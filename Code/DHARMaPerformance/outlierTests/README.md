# Calibration of testOutliers() (#653, #202)

`outlierTests.R` compares, under H0, the binomial outlier test, the bootstrap of DHARMa >= 0.5.2 (each simulation against the other nSim - 1) and the bootstrap of DHARMa <= 0.5.1 (resampling with replacement), for PIT and traditional residuals of continuous, integer and non-integer discrete responses, and for refit = TRUE. Details and the run command are in the header of the script.

- `outlierTests.csv`: summary table (committed). Produced with DHARMa 0.5.2 from branch i653-pitCalibration (PR #658), R 4.6.2, 300 replicates per scenario, seeds set per replicate.
- `outlierTests.rds`: raw p-values per replicate (not committed, regenerated by the script).

## Results and decisions (November 2026, PR #658)

**Question.** With the randomized PIT residuals of #653, which test should `testOutliers(type = "default")` use? Before, it used the bootstrap for integer responses with nObs <= 500 and the binomial test otherwise, because the binomial expectation 1/(nSim + 1) per margin was thought to be wrong for integer responses.

**Binomial test.** Under H0, the probability that an observation lies below (above) all nSim simulations is 1/(nSim + 1) if observation and simulations are exchangeable and ties are broken at random. This holds for PIT residuals (ties are randomized, #653) and for traditional residuals of integer responses (observed and simulated values get independent U(-0.5, 0.5) noise). Rejection rates at alpha = 0.05 (n = 500, nSim = 50) were 3.7-5.7% for PIT residuals and 2.0-5.7% for traditional residuals of normal, Poisson and Bernoulli data. The exception are traditional residuals of discrete non-integer responses (here Poisson / 2), which are not randomized: observations tied with the smallest or largest simulation are not outliers, the outlier frequency drops to 0.017 (expected 0.039; the exact value for these data is 0.016), and the binomial test rejected in 85% of the cases. With refit = TRUE (n = 200, correctly specified lm and Poisson GLM), it rejected in 1.0% and 3.0%, i.e. it is conservative, as expected for fitted models.

**Bootstrap of DHARMa <= 0.5.1.** Resampling nSim simulations with replacement duplicates simulations, so that more simulated "observations" fall outside the resampled range; the expected outlier frequency was 0.055-0.062 instead of 0.039 for continuous and count data (n = 500, nSim = 50; 0.054-0.062 with refit = TRUE). As a consequence, the bootstrap rejected H0 in 30-61% of the cases for these data (n = 500, nSim = 50; 10-23% with refit = TRUE), presumably mostly with too few outliers, as its expectation is too high (the direction of the rejections was not recorded).

**New bootstrap.** Each of nBoot simulations is compared with the other nSim - 1 simulations, and the outlier frequency is rescaled by nSim / (nSim + 1) to the expectation with nSim simulations. Its expectation then matches 2 / (nSim + 1) (0.0392 in all scenarios except non-integer ties, where it estimates the lower frequency of 0.016 correctly). Because the null distribution is estimated from only nBoot replicates of the same simulations, it still rejects somewhat too often: 5.0-9.3% at n = 500, nSim = 50 (1.7-2.7% with refit = TRUE).

**Decision.** `type = "default"` uses the binomial test, except for traditional residuals (incl. refit = TRUE) with duplicated non-integer simulated values and nObs <= 500, where it uses the bootstrap (for nObs > 500, the binomial test is kept because of the run time; `getQuantile()` already shows a message about duplicate non-integer values). The binomial label says "with approximate expectations" only in that case, and the message that the binomial test may have inflated type I error rates for integer responses was removed. Continuous traditional residuals and refit = TRUE without such ties keep the binomial test, as in DHARMa 0.5.1: there, the bootstrap was more liberal (normal, traditional: 7.3% vs 5.7%) or not better (refit lm: 1.7% vs 1.0%).

**Rejected options.**
- Bootstrap as default for traditional residuals of integer responses (decided first): the binomial test is exact there and the bootstrap rejects more often than nominal.
- Bootstrap as default for all traditional residuals of non-integer responses (decided second): without ties, the binomial expectation is exact, so this would only change results of DHARMa 0.5.1 without benefit.
- Binomial test everywhere: fails for non-integer ties (85% rejections above).
- Leave-one-out bootstrap without rescaling: its expectation is 2 / nSim instead of 2 / (nSim + 1), a constant bias whose weight against the standard error grows with n and is largest for small nSim.
- Poisson-binomial null distribution from the ties at the pooled minimum and maximum (#202): not needed for PIT residuals and integer responses; it would remain an option for the non-integer case.
